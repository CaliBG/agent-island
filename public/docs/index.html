AISLAND / DOCUMENTATION

从这里，开始登岛。

安装应用，体验小岛，再把你自己的 Agent 接进来。
适用于 v0.3.37 预览版。

安装与打开

应用本身不需要 Node.js 或 Python。Claude Code、Codex、WorkBuddy、Antigravity 的 Hooks 需要 Python 3.9+；对应 SDK 需要 Node.js 20+ 或 Python 3.9+。

macOS · Apple Silicon

  1. 从下载页面获取 DMG，打开后将 AISLAND 拖入 Applications（应用程序）。
  2. 从应用程序中启动 AISLAND。
  3. 当前提供 M 系列芯片版本，尚未提供 Intel 安装包。

桌面界面跟随系统明暗模式。macOS 开关使用 AppKit NSSwitch；Windows 设置使用微软官方 Fluent UI React 组件，并保留系统窗口按钮。

Windows · x64

  1. 下载 EXE 安装程序，按提示安装并打开。

当前是未签名的预览版，尚未完成 Apple Developer ID 公证或 Windows Authenticode 签名。首次打开可能出现系统来源提示，请先确认下载地址和文件校验信息。Mac 已完成自动化验证，Windows 安装包已构建，尚待实机验证。

应用常驻菜单栏或系统托盘。关闭管理窗口不会退出应用；如需完全退出，请使用托盘菜单中的「退出」。

接入 Claude Code

  1. 启动 AISLAND，打开「工具接入」，点击 Claude Code 的「安装接入」。这一步需要 Python 3.9+。
  2. 在项目终端运行 claude。已启动的会话可重启一次或用 /hooks 检查配置。
  3. 提交真实任务后，小岛显示运行状态；权限确认和问题回答会返回当前 Claude Code 会话。

保留你已有的 Hooks、模型和权限配置。只有明确确认才允许操作；小岛不在线或请求超时，回到 Claude Code 原有交互。计划确认仍在终端处理。

快捷键：macOS 为 Cmd + Shift + Space，Windows 为 Ctrl + Shift + Space。

Codex、Antigravity 与接入助手

在应用「工具接入」中打开接入助手。先检查 Python 3.9+ 和 Codex，再安装接入配置。助手保留已有配置并备份，不会更改权限策略。

Codex 桌面软件

  1. 点击「安装 Codex 接入」，等待写入完成。
  2. 点击「打开审核终端」，在 Codex 中输入 /hooks，审核并信任「AISLAND · Codex」条目。审核不会自动进行。
  3. 回到小岛点击「重新检查」。显示已启用并信任后，重启 Codex 桌面端并开启新任务。

支持真实进度、工具调用、权限确认、结束与中断。问答和计划仍在 Codex 中完成。用户级 Hooks 也会被同一配置下的 CLI 加载；小岛跳转唤起桌面软件，不定位具体聊天。

续发限制：Codex 桌面端占用原会话时，官方接口可能拒绝其他进程写入。此时 AISLAND 会保留指令并提示尚未发送；不会将排队当作已执行，也不会另建对话。

Antigravity

在对应接入卡片点击安装，重启 Antigravity 并开启新任务。支持进度、工具调用与后台任务状态。权限和问答在 Antigravity 内处理。

登录后自动运行

「登录后自动启动小岛」与「启动时运行接入检查」是独立开关，默认关闭。前者运行本机服务；后者只读检查环境与 Hooks 状态，发现未完成步骤时显示助手，不自动批准 Hooks。

应用先放入应用程序目录或通过 Windows 安装程序安装。系统要求批准登录项时，请在系统设置中完成；未签名 macOS 预览包的登录启动可能受系统限制。界面显示系统实际状态，不能等同于已经实测重启。

「已配置」不代表已经连接。收到真实 Hook 后才显示事件回执。安装脚本与配置不上传网站。

接入你的 Agent

第一次接入：复制一段指令

  1. 在 AISLAND 打开「工具接入」，点击「复制接入指令」。
  2. 粘贴到这台电脑上的 Agent 对话中，让它按指令完成接入配置。
  3. 回到 AISLAND。收到对应 Agent 的回执后，导览会自动显示「本机通信已验证」。

无需手动填写端口或拼接命令，SDK 路径和接入说明会自动加入指令。适用于能读取本机文件、执行命令的 Agent；仅聊天的网页应用不能靠粘贴文字接入。验证不会创建演示任务。真实进度、审批和问答需由 Agent 接入对应的回调，后台派发能力单独判断。SDK、地址和示例命令仍可在「高级接入」中找到。

开发者：手动接入 SDK

先启动 AISLAND，再把 SDK 文件复制到你自己的项目。SDK 会读取当前用户目录下的本机连接信息，向应用报告状态。无需第三方依赖，也不需要填写 AI 服务密钥。

下载 Node.js SDK ↓下载 Python SDK ↓下载完整 Node.js 示例 ↓

Node.js

将以下代码保存为 connect.mjs，与 agent-island.mjs 放在同一个目录，然后运行 node connect.mjs。

import { AgentIsland } from './agent-island.mjs';

const island = new AgentIsland({
  agent: 'My Agent', title: '整理项目文档'
});

await island.start('正在读取项目…');
await island.tool('Read', '检查 README.md');
await island.complete('文档整理完成');

Python

将以下代码保存为 connect.py，与 agent_island.py 放在同一目录。运行 python3 connect.py（Windows 也可用 py connect.py）。

from agent_island import AgentIsland

island = AgentIsland(
    agent="My Agent", title="整理项目文档"
)

island.start("正在读取项目…")
island.send("tool.start", tool="Read",
            content="检查 README.md")
island.complete("文档整理完成")

本地 HTTP 接口

应用在 ~/.agent-island/connection.json 中写入端点和令牌。Windows 中 ~ 指当前用户目录。默认端口为 24678；如被占用，会自动选择空闲端口。SDK 每次请求重新读取连接文件。

其他语言可通过 POST /v1/events 发送事件，请携带 Authorization: Bearer <token>。完整事件结构见本地 HTTP 协议。

审批与问答

你可以将操作的命令、说明及 diff 提交到小岛，等待用户决定。SDK 只传递状态与反馈，不会代替你执行操作。

const result = await island.approve({
  title: '请确认本次操作',
  command: 'echo "Hello from AISLAND"',
  content: '仅展示操作预览，本示例不会执行命令。'
});

if (result.decision === 'allow') {
  await island.complete('用户已确认。');
} else {
  await island.complete('操作未获批准。');
}

审批最多等待约 10 分钟。超时、断线、会话结束、应用退出或重启，都不会自动批准。接入方必须把错误与 cancel 视为未批准，不应在捕获异常后继续执行待确认操作。

Node.js SDK 还提供 ask()（单选、多选、自定义回答）、plan()（计划与反馈）和 usage()（真实上报的用量）。可下载完整示例体验双向交互。Python 可用 send() 发送协议定义的其他事件。

Gemini、Cursor、MiniMax 与智谱

v0.3.29 新增 Gemini CLI 与 Cursor 的官方 Hooks 观察接入。在「工具接入」安装后开启新会话，收到任务事件才显示已收到事件。支持任务和工具状态、最终回复；审批与续发仍在原应用完成。Gemini CLI 与 Gemini 网页是不同的接入。

MiniMax Code 使用本地 Plugin V1 Hooks。安装官方 MiniMax Code 和 mcode 命令后，在「工具接入 → MiniMax Code」点击「接入」：AISLAND 会查询当前配置的本地插件目录，安装、启用并检查插件。更新前备份旧插件，遇到其他同名插件不会覆盖。也可以展开说明选择「手动安装插件」。开始真实任务后收到事件，才说明进度链路已接通；审批、问答与续发仍在 MiniMax Code 完成。MiniMax Design 不适用。

智谱 GLM 可通过已配置 GLM 的 Claude Code 接入：安装 Claude Code Hooks 后，根据事件明确提供的模型标识显示智谱，仍续发到同一个 Claude Code 会话。不会自动连接智谱清言或 AutoGLM。智谱清言客户端已单独列出，目前原会话读取、进度同步与后台续发仍待实机验证；开放平台的助手 API 不代表已经接通清言客户端。

豆包电脑版、Grok 原有对话的状态同步与后台续发目前尚未接通；公开模型 API 不代表可以读取这些产品里的现有对话。应用会明确显示限制。

新适配器已通过隔离 Hook 进程与本地桥的协议测试；所有新客户端的用户账户实机验收仍待完成。官方参考：Gemini CLI Hooks、Cursor Hooks、MiniMax Hooks、智谱接入指南。

数据与隐私

桌面应用的桥接服务只监听 127.0.0.1，不向局域网开放。请求需通过本机令牌验证，并拒绝携带浏览器 Origin 的请求。不要公开或分享 connection.json。

会话文本与操作预览保存在 ~/.agent-island/state.json。记录默认保留 7 天，下次启动时清理过期记录。在偏好设置中可打开数据目录。

AISLAND 默认只在本机运行，不设置遥测。主动启用手机连接后，进度摘要和手机指令在设备上用 AES-256-GCM 加密，再经过你配置的 Cloudflare Workers / D1 同步；服务端不持有解密密钥。电脑超过 24 小时不再同步时，服务会清理旧连接。手机配对信息保存在设备本地，配对链接相当于访问凭据，不要分享。你所接入的 AI 工具可能有自己的网络行为与数据策略，请以对应工具的设置为准。

本官网不嵌入分析追踪器，也不设置账户系统。网页由 GitHub Pages 托管，安装包通过 GitHub Releases 分发；访问与下载产生的基础服务日志由 GitHub 按其隐私声明处理。

手机同步与控制

自部署用户可下载免费同步服务部署包，按其中 README 设置 Workers 和 D1。

  1. 在电脑打开「设置 → 手机与远程」，配置你自己的 Cloudflare Workers 免费同步服务，然后生成配对码。已配置服务的电脑可直接生成二维码。
  2. 手机打开移动端，扫码或粘贴配对链接。二维码仅用于配对，有效期 10 分钟。
  3. iPhone 可通过 Safari「分享 → 添加到主屏幕」免费使用。Android 可从官网下载 APK 安装；原生预览版尚待真机验证。
  4. 按需在电脑分别允许「发送 Agent 任务」「调整保持唤醒」「打开远程控制软件」。三项默认关闭。

前台约 5 秒刷新，手机进入后台后暂停轮询。电脑需运行 AISLAND 并联网；离线时只能查看最后同步的数据。发送后的“已排队”不等于执行成功，请以电脑返回的回执为准。保持唤醒不会解除手动锁屏，远程软件仍使用自身的登录和验证。

同步后端使用 Workers / D1 免费额度，超额时可能暂停，不会自动升级付费。AI 工具本身的订阅、额度以及第三方远程软件的收费由各厂商决定。iOS 原生工程已编译验证，尚未提供 App Store / TestFlight 安装。

从小岛发送任务

点击「给 Agent 新任务」，选择 Agent 和原对话；鼠标靠近分支右侧的状态按钮会自动弹出输入气泡；点击输入框后取得键盘焦点，已结束的会话也可正常输入。Codex、Claude Code 支持原会话续发，保留上下文；运行中可以排队发送，任务完成后自动续发，每个会话最多一条，可撤回编辑。应用重启或当前任务异常后，队列会暂停，需确认后重新提交。

Codex 使用官方 app-server 恢复同一个会话，桌面客户端可能需要重新打开对话才能显示新内容；Claude Code 使用官方 Agent SDK。两者沿用本机已有登录，不要求另外填写 API Key。需要审批时，在小岛逐次确认。

接入 WorkBuddy

  1. 打开「设置 → Agent 接入 → WorkBuddy → 接入」。
  2. 在 WorkBuddy 审核新增 Hooks，再开启新会话；旧会话可能需要重启后加载配置。
  3. 开始真实任务后，设置页会显示「已收到事件」和时间；「已配置」只代表配置已写入。

同步任务、工具调用和结束状态。v0.3.37 修复 macOS WorkBuddy 5.11.3 后台续发：在小岛的会话气泡输入并发送，系统核对原会话、完整输入和新增用户消息后才确认送达。已实测收到 Agent 回复，期间没有切换到 WorkBuddy 前台。需要辅助功能授权，且 WorkBuddy 窗口保持开启；可被其他窗口遮挡，但不能隐藏或最小化。已有草稿不会覆盖；目标不明确或回执不明时保留指令，不自动重发。Windows 实机仍待验收。Antigravity 和其他观察型接入尚不支持已验证的原对话续发。审批与问答仍在 WorkBuddy 完成。

常见问题

示例提示找不到 connection.json

先打开 AISLAND，确认「工具接入」显示本地连接正常。SDK 和应用需要在同一台电脑、同一用户下运行。自定义数据路径时，可使用 AGENT_ISLAND_HOME 指向相应目录。

小岛没有显示在预期位置

使用快捷键唤起，或从托盘菜单打开管理窗口，检查偏好设置中的显示器与浮动方式。显示器断开后，应用会回退到可用屏幕。

MacBook 没有感觉到震动

在设置 → 外观与交互中开启「触控板触感」，将手指放在支持 Force Touch 的触控板上，点击「试一下」。每次进入只发送一次触感，默认清脆模式，可切换标准或轻触。系统公开接口不支持改变单次震动振幅。区域内移动不重复，移出再进入重新触发。声音开关与触感开关相互独立，普通鼠标本身不会震动。

无法跳回终端

macOS 首次定位 Terminal / iTerm2 会话可能需要系统自动化权限。Windows 在管理员窗口或某些全屏应用下可能拒绝切换焦点。若无法定位会话，可先从工具界面打开对应项目目录。
