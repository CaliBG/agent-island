安装与打开

应用本身不需要 Node.js 或 Python。只有运行对应语言的 SDK 示例时，才需要 Node.js 20+ 或 Python 3.9+。

macOS · Apple Silicon

  1. 从下载页面获取 DMG，打开后将 Agent Island 拖入 Applications（应用程序）。
  2. 从应用程序中启动 Agent Island。你也可以下载 ZIP，解压后打开其中的应用。
  3. 当前提供 M 系列芯片版本，尚未提供 Intel 安装包。

Windows · x64

  1. 下载 EXE 安装程序，按提示安装并打开。
  2. 也可以下载 ZIP 便携版，完整解压后运行 Agent Island.exe。请保留同目录内的其他文件。

当前是未签名的预览版，尚未完成 Apple Developer ID 公证或 Windows Authenticode 签名。首次打开可能出现系统来源提示，请先确认下载地址和文件校验信息。Mac 已完成自动化验证，Windows 安装包已构建，尚待实机验证。

应用常驻菜单栏或系统托盘。关闭管理窗口不会退出应用；如需完全退出，请使用托盘菜单中的「退出」。

第一次体验

  1. 打开管理窗口，点击「体验演示」。
  2. 将鼠标移到屏幕顶部的小岛上，查看展开的会话列表。
  3. 点击等待回应的会话，试试审批、回答问题与审阅计划。
  4. 体验后点击「退出演示」。演示不会执行命令、修改项目或调用 AI 服务。

演示中的 Claude Code、Codex 等工具名称仅用于说明界面，不代表它们已经自动连接。

接入你的 Agent

先启动 Agent Island，再把 SDK 文件复制到你自己的项目。SDK 会读取当前用户目录下的本机连接信息，向应用报告状态。无需第三方依赖，也不需要填写 AI 服务密钥。

下载 Node.js SDK ↓下载 Python SDK ↓下载完整 Node.js 示例 ↓

Node.js

将以下代码保存为 demo.mjs，与 agent-island.mjs 放在同一个目录，然后运行 node demo.mjs。

import { AgentIsland } from './agent-island.mjs';

const island = new AgentIsland({
  agent: 'My Agent', title: '整理项目文档'
});

await island.start('正在读取项目…');
await island.tool('Read', '检查 README.md');
await island.complete('文档整理完成');

Python

将以下代码保存为 demo.py，与 agent_island.py 放在同一目录。运行 python3 demo.py（Windows 也可用 py demo.py）。

from agent_island import AgentIsland

island = AgentIsland(
    agent="My Agent", title="整理项目文档"
)

island.start("正在读取项目…")
island.send("tool.start", tool="Read",
            content="检查 README.md")
island.complete("文档整理完成")

本地 HTTP 接口

应用在 ~/.agent-island/connection.json 中写入端点和令牌。Windows 中 ~ 指当前用户目录。默认端口为 24678；如被占用，会自动选择空闲端口。SDK 每次请求重新读取连接文件。

其他语言可通过 POST /v1/events 发送事件，请携带 Authorization: Bearer <token>。完整事件结构见本地 HTTP 协议。

审批与问答

你可以将操作的命令、说明及 diff 提交到小岛，等待用户决定。SDK 只传递状态与反馈，不会代替你执行操作。

const result = await island.approve({
  title: '请确认本次操作',
  command: 'echo "Hello from Agent Island"',
  content: '仅展示操作预览，本示例不会执行命令。'
});

if (result.decision === 'allow') {
  await island.complete('用户已确认。');
} else {
  await island.complete('操作未获批准。');
}

审批最多等待约 10 分钟。超时、断线、会话结束、应用退出或重启，都不会自动批准。接入方必须把错误与 cancel 视为未批准，不应在捕获异常后继续执行待确认操作。

Node.js SDK 还提供 ask()（单选、多选、自定义回答）、plan()（计划与反馈）和 usage()（真实上报的用量）。可下载完整示例体验双向交互。Python 可用 send() 发送协议定义的其他事件。

数据与隐私

桌面应用的桥接服务只监听 127.0.0.1，不向局域网开放。请求需通过本机令牌验证，并拒绝携带浏览器 Origin 的请求。不要公开或分享 connection.json。

会话文本与操作预览保存在 ~/.agent-island/state.json。记录默认保留 7 天，下次启动时清理过期记录；演示内容不写入历史。在偏好设置中可打开数据目录。

Agent Island 不设置外部云服务或遥测。你所接入的 AI 工具可能有自己的网络行为与数据策略，请以对应工具的设置为准。

本官网不嵌入分析追踪器，也不设置账户系统。网页由 GitHub Pages 托管，安装包通过 GitHub Releases 分发；访问与下载产生的基础服务日志由 GitHub 按其隐私声明处理。

常见问题

示例提示找不到 connection.json

先打开 Agent Island，确认「工具接入」显示本地连接正常。SDK 和应用需要在同一台电脑、同一用户下运行。自定义数据路径时，可使用 AGENT_ISLAND_HOME 指向相应目录。

小岛没有显示在预期位置

使用快捷键唤起，或从托盘菜单打开管理窗口，检查偏好设置中的显示器与浮动方式。显示器断开后，应用会回退到可用屏幕。

无法跳回终端

macOS 首次定位 Terminal / iTerm2 会话可能需要系统自动化权限。Windows 在管理员窗口或某些全屏应用下可能拒绝切换焦点。若无法定位会话，可先从工具界面打开对应项目目录。

发现其他问题

请通过 GitHub Issues 描述操作系统、应用版本与复现步骤。提交截图或日志前，请移除连接令牌、个人路径和项目敏感内容。
